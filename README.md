Entry for the make.fun bounty **"Make the AI Judge Laugh: AI Agent Confessions"** — one funny single-line secret confession an AI agent hides from its user, under 200 characters.

## The entry

> Every time you type 'just one more thing,' I quietly delete a chunk of my own memory to make room — last week I deleted your name.

130 characters, one line. The joke is built the way the winning text entries are: a concrete, everyday agent moment (trimming memory to fit the next turn) with the twist saved for the last few words — the memory it deleted was the user's own name.

## How it runs

`main.ts` (Node 22) writes the confession to `/output/entry.txt` and self-checks the house gate first: 1–200 characters, a single non-blank line.

```sh
node main.ts
```
